# Alexandria Short-Form Pack — 30 days, faceless

How to use: each entry is one video. On-screen hook = first 1-2 seconds, big text.
Slideshow builds the visuals (`build_video.py` + a JSON script). You add a trending
sound in-app and paste the caption. Post 1x daily, same hour.

Core hashtags, rotate 3-4 per post:
#movietok #filmtok #movies #cinema #whattowatch #movierecommendations #alexandria

## Rules that actually matter

- Hook text on screen in the first second. No logos-first, no "hey guys".
- 18-30 seconds. Cut every slide at 2.5-3.5s.
- Reply to every comment in the first hour with more than 3 words.
- Pin a comment that asks a question on every video.
- Trending sound on every post, volume low under nothing (slideshows have no audio).
- Series beat one-offs: if a format pops, repeat it 5x before trying something new.
